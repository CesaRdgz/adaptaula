DESCRIPCIÓN FUNCIONAL DE LA APLICACIÓN

Generador de documentos y exámenes adaptados para Educación Primaria

1. OBJETIVO PRINCIP

La aplicación no debe crear un examen nuevo desde cero. Debe trabajar sobre un documento original que el profesor proporciona y generar una versión adaptada del mismo.

Debe mantener:

- Los contenidos curriculares originales.
- Los objetivos de aprendizaje.
- Los conocimientos que se quieren evaluar.
- El nivel curricular del examen.
- La intención de cada pregunta o actividad.

La adaptación debe facilitar el acceso a la información y la respuesta del alumno, sin modificar lo que se pretende evaluar.

2. FUNCIONAMIENTO GENERAL

El funcionamiento tendrá cuatro pasos:

1. El profesor sube el documento original (PDF, Word o imagen).
2. Selecciona las adaptaciones que necesita.
3. La aplicación procesa el documento y realiza los cambios.
4. Genera un nuevo documento adaptado, editable y listo para imprimir.

Debe existir una vista previa para que el docente pueda revisar y modificar el resultado antes de descargarlo.

3. FUNCIONES DE ADAPTACIÓN

A. Adaptación visual y de formato

- Resaltar en negrita las palabras clave de cada enunciado.
- Aumentar el tamaño de letra.
- Utilizar tipografías claras y de fácil lectura.
- Aumentar el interlineado.
- Separar visualmente los diferentes ejercicios.
- Aumentar los espacios en blanco.
- Evitar que las preguntas queden demasiado juntas.
- Incorporar recuadros para destacar instrucciones.
- Mantener una estructura limpia y ordenada.
- Evitar que una pregunta quede dividida entre dos páginas.

B. Adaptación de las instrucciones y los enunciados

- Simplificar los enunciados utilizando frases cortas y vocabulario sencillo.
- Eliminar información innecesaria que dificulte la comprensión.
- Separar las instrucciones largas en pasos.
- Destacar qué tiene que hacer exactamente el alumno.
- Sustituir instrucciones complejas por instrucciones directas.
- Evitar dobles negaciones y expresiones ambiguas.

Importante: no modificar el contenido conceptual ni dar pistas que revelen la respuesta.

C. Adaptación de la cantidad y organización de ejercicios

- Reducir el número de apartados repetitivos.
- Seleccionar ejercicios representativos cuando existan actividades muy similares.
- Reducir el número de operaciones dentro de un problema cuando el docente lo autorice.
- Dividir actividades complejas en pasos más pequeños.
- Presentar un ejercicio por bloque visual.
- Mantener la variedad de contenidos que se quieren evaluar.

D. Adaptación de los espacios de respuesta

- Incorporar líneas para escribir las respuestas.
- Añadir espacios amplios para desarrollar operaciones.
- Crear cuadrículas para colocar números y realizar cálculos.
- Incorporar tablas para organizar respuestas.
- Añadir recuadros para respuestas cortas.
- Dejar espacio suficiente para dibujos, esquemas o representaciones.
- Adaptar el espacio disponible a la extensión de la respuesta esperada.

E. Adaptación de problemas matemáticos

- Simplificar la redacción sin cambiar la operación matemática que se evalúa.
- Destacar los datos importantes.
- Separar el enunciado de los datos.
- Incorporar apartados visuales para identificar:
  - Datos.
  - Operación.
  - Resolución.
  - Solución.
- Incorporar cuadrículas para realizar operaciones.
- Reducir apartados repetitivos cuando el profesor lo indique.
- Facilitar la identificación de qué pregunta se debe resolver.

4. SISTEMA DE SELECCIÓN DE ADAPTACIONES

La aplicación debe permitir seleccionar individualmente las modificaciones que se quieren realizar.

El docente podrá activar varias opciones a la vez y guardar sus propias configuraciones.

5. CONSERVACIÓN DEL DOCUMENTO ORIGINAL

Este aspecto es fundamental:

- El documento original nunca debe modificarse.
- La aplicación debe generar una copia adaptada.
- Debe conservar las imágenes, gráficos, tablas y elementos necesarios.
- Debe respetar el orden de los contenidos.
- Debe evitar eliminar información curricular importante.
- Debe permitir comparar el documento original y el adaptado.

6. FORMATOS DE SALIDA

La aplicación debe permitir descargar:

- Word editable (.docx).
- PDF listo para imprimir.

También debe permitir volver a editar la adaptación antes de descargarla.

7. CONTROL DEL DOCENTE

La inteligencia artificial puede proponer las adaptaciones, pero el profesor debe tener siempre la última palabra.

Debe poder:

- Aceptar o rechazar cada modificación.
- Editar los enunciados.
- Recuperar un apartado eliminado.
- Cambiar espacios y tamaños.
- Añadir o quitar ejercicios.
- Revisar que los objetivos de evaluación se mantienen.

8. FINALIDAD PEDAGÓGICA

La finalidad no es reducir el aprendizaje ni los conocimientos que puede alcanzar el alumno.

Se trata de eliminar barreras de acceso a la información, comprensión, organización y expresión para que pueda demostrar lo que realmente sabe.

Principio fundamental: adaptar la forma de presentar y responder a una evaluación, sin perder de vista aquello que se quiere evaluar.
